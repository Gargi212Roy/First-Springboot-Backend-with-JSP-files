# First Spring Boot Backend with JSP Files

A basic **Spring Boot MVC** application created using [Spring Initializr](https://start.spring.io/).
The app uses **JSP views** rendered via **Apache Tomcat Jasper** and runs on an **embedded Tomcat server** at port **8080**.

This project implements a simple **Job Portal** that allows you to:

* Add new job listings
* View existing and newly added jobs

> **Note:** No database is used. All job data is stored in memory, so jobs will disappear when the application is stopped or restarted.

## Features

* Spring Boot MVC architecture
* JSP integration with Apache Tomcat Jasper
* In-memory job storage
* Local deployment on port 8080
